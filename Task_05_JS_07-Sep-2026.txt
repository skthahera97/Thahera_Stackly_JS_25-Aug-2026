## 📌 Variables & Data Types (Questions 1-8)

### Q1: What is the difference between var, let, and const?

var: Allows both redeclaration and reassignment within its scope.
let: Allows reassignment but does not allow redeclaration within the same scope.
const: Does not allow either redeclaration or reassignment after initialization.


### Q2: Can you re-declare a variable with var? What about let and const?

## 📌 Operators (Questions 9-14)

### Q9: What is the difference between == and ===?
== → Compares values after type conversion.
=== → Compares both value and data type.

5 == "5"   // true
5 === "5"  // false

### Q10: What is the difference between ++i and i++?
++i (pre-increment) increments the value first and then returns it, while i++ (post-increment) returns the current value first and then increments it

let i = 5;
console.log(++i); // 6

let j = 5;

console.log(j++); // 5
console.log(j);   // 6

### Q12: What are logical operators? Explain with examples.

Logical operators are used to combine multiple conditions, make decisions, and evaluate 
Boolean expressions. JavaScript has three main logical operators:

1. && — AND Operator
Returns true only when both conditions are true.
2. || — OR Operator
Returns true when at least one condition is true.
3. ! — NOT Operator
The NOT operator reverses the Boolean result.

Example Program
let age = 20;
let hasID = true;

console.log("AND (&&):", age >= 18 && hasID);
console.log("OR (||):", age < 18 || hasID);
console.log("NOT (!):", !hasID);

## 📌 Type Casting (Questions 15-17)

### Q15: What is the difference between implicit and explicit type casting?
1.Implicit: JavaScript automatically converts the type.
let x = "10";
let y = 5;
console.log(x - y); // 5

2.Explicit: Programmer manually converts the type.
let x = "10";
console.log(Number(x)); // 10

## 📌 Loops (Questions 22-25)

### Q22: What is the difference between while and do-while?
while:Condition is checked before execution.
let i = 1;

while (i <= 3) {
    console.log(i);
    i++;
}

do-while: Code executes at least once, then condition is checked.
let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 3);
