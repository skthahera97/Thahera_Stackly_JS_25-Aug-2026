JavaScript Basics — 50 Questions & Answers

Variables

1. What is a variable in JavaScript?
A variable is a named container used to store data values.

2. What are the three keywords used to create variables?
var, let, and const.

3. Syntax using var:
var variableName = value;

4. Syntax using let:
let variableName = value;

5. Syntax using const:
const variableName = value;

6. What is declaration?
Declaration means creating a variable without necessarily assigning a value.
let age;

7. What is initialization?
Initialization means assigning the first value to a variable.
let age = 25;

8. What is reassignment?
Changing the existing value of a variable.
let age = 25;
age = 30;

9. What is redeclaration?
Creating a variable with the same name again in the same scope.
var x = 10;
var x = 20;

10. Which keyword allows redeclaration?
var allows redeclaration in the same scope.

11. Which keyword allows reassignment?
Both var and let allow reassignment.
12. Which keyword requires initialization when declared?
const.
const age = 25;
This is invalid:
const age;

13. Identify declaration and initialization:
let age = 25;
Declaration: let age
Initialization: age = 25

36. Create pi:

37. Can a const variable be reassigned?
No.
const price = 500;
price = 1000; // Error

38. Can a const variable be redeclared?
No.
const x = 10;
const x = 20; // Error

39. What is wrong here?
const age;
age = 25;
A const variable must be initialized at the time of declaration.
Correct:
const age = 25;

40. What happens here?

price = 1000;
It produces a TypeError because a const variable cannot be reassigned.

Printing & Console

46. Print Hello World:
console.log("Hello World");
Output:
Hello World

47. Print 500:

48. Purpose of console.warn():
Used to display warning messages in the browser console.
console.warn("This is a warning");

49. Purpose of console.error():
Used to display error messages in the browser console.
console.error("Something went wrong");

50. Purpose of each function:

Purpose

Takes input from the user

Asks the user to confirm/cancel

Examples:
alert("Welcome!");

Age: 25
Mark: 85
